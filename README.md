# FineDust_prediction

In this project, fine dust (PM2.5 and PM10) concentrations were predicted using two
machine learning models: Random Forest Regression and Long Short-Term Memory
(LSTM) networks. The project aimed to compare both models' performances and optimize
them by applying various techniques to prevent overfitting.
Problem Statement

## Problem:
In South Korea, fine dust monitoring presents significant academic and practical
challenges due to the unique characteristics of the residential environment and
geographical factors. A key issue is the lack of observation stations in cities and provinces
outside of major metropolitan areas. This is largely because the stations are typically
installed based on population density, resulting in fewer accurate air quality
measurements in smaller towns and rural areas. For example, rural regions have, on
average, seven times fewer monitoring stations compared to the capital city of Seoul.


## Objective:
The goal of this project was to predict futurePM2.5 levels using machine learning models
with past fine dust data.

## Data Collection
Data source:
https://www.data.go.kr/en/data/15089266/fileData.do
The fine dust data is sourced from Public Data Portal(data.go.kr). This Public Data Portal
(data.go.kr) is a South Korean government initiative that provides open access to a wide
range of public datasets for citizens, businesses, and developers. The portal offers data
across various sectors such as health, environment, transportation, and finance.
